# CMSC471 Assignment 2: White Hat / Black Hat

Team: Kiran Manoj, Mihail Gjoni, Tong Zhan

Live site: https://cmsc-471-group.github.io/Assignment-2/

## Files
- `index.html` - the page (both charts + write-ups)
- `css/styles.css`
- `js/data.js` - loads `data/gentrification.csv`, both charts use it
- `js/whitehat.js` - Tong
- `js/blackhat.js` - Mihail
- `data/gentrification.csv` - tract-level data from BuzzFeed News (2000 vs 2013-2017 ACS)
- `data/cities/` - smaller per-city files (from BuzzFeed's `output/for_maps`)

## Run locally
Open the folder in VS Code and use the Live Server extension (right click index.html > Open with Live Server).
Opening the html file directly won't load the CSV.
